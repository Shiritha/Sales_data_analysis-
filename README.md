## Sales Dashboard — Excel + Power BI

### Objective
Analyze retail sales data to identify revenue trends,
regional performance, and profit opportunities.

### Tools Used
Excel (data cleaning, pivot tables) | Power BI (dashboard)

### Dataset
Kaggle Superstore — 9,994 rows, 21 columns

### Key Findings
1. Technology = highest revenue category ($836K)
2. West region = top performing region
3. Tables sub-category = highest loss-maker
